# Work Plan

학기 시간표, 시험, 자격증, 고정 일정을 한 화면에서 관리하는 일정 대시보드.

## 화면

- **📋 일간 계획:** 그날의 고정 일정, 내 일정, 자동으로 배분된 ✏️ 공부 블록을 보여준다. 블록마다 **주차 완료** 체크와 "어디까지 했는지" 기록 칸이 있고, 📝 하루 기록도 따로 남긴다.
- **🗓️ 주간 계획:** 이번 주 시간표에 공부 블록을 자동으로 배분해 보여준다. 빈 시간이 모자라면 ⚠️로 알려 준다.
- **📆 월간:** 바쁜 날은 진하게, 시험 날짜는 🎯로 표시한다.
- **📚 과목 진도:** 중간고사가 없는 과목은 1주차부터, 본 과목은 9주차부터 시험 전 주까지 주차별로 체크한다. 필요 없으면 탭의 ✕로 숨긴다.
- **＋ 탭 추가:** 자격증 준비·운동처럼 나만의 탭(체크리스트 + 메모)을 만들고 ✕로 지운다.
- **✅ 이번 주 준비할 것:** 주마다 체크리스트를 쓴다. 새 주에는 지난주 목록이 체크 해제된 채로 이어진다.

## 공부 자동 배분 규칙 (`logic.js` → `planWeek`)

- 이미 배운 주차 중 체크하지 않은 주차를 "시험까지 남은 주 수"로 나눠, 이번 주에 할 분량을 정한다.
- 블록 하나는 한 주차 분량이고, 길이는 과목 난이도로 정한다(상 120분 · 중 90분 · 하 60분, 편집 창에서 변경). 09~23시 빈 시간에만 넣고, 점심(12~13시)·저녁(18~19시)은 비우며, 하루 공부는 최대 4.5시간이다.
- 이번 주에 다 못 넣은 주차는 체크하지 않으면 다음 주 계획으로 자동으로 넘어간다.
- 시험이 가까운 과목부터, 여유 시간이 많은 날부터 채운다. 같은 과목은 하루에 몰리지 않게 한다.

## 이렇게 쓰기

- **매일 아침:** 📋 일간 계획에서 오늘 공부 블록을 확인한다.
- **공부 후:** 어디까지 했는지 적는다. 그 주차를 다 끝냈으면 **주차 완료**를 체크한다. 그러면 다음 계획에서 빠진다.
- **일요일 밤:** 🗓️ 주간 계획에서 다음 주를 확인한다. ⚠️가 뜨면 일정을 조정한다.
- **시간표·시험이 바뀌면:** ⚙️ **시간표·시험 편집**에서 고친다.

## 연습 기간과 2027년 시작

- 2026/12/31까지는 연습 기간이다. 화면 위에 🧪 안내가 뜬다.
- 2027년에 처음 앱을 열면 한 번만 2026년 일정·공부 기록·준비할 것·주차 체크·편집한 시간표를 정리한다. 지우기 전에 사본(`wp.practice`)을 보관하고, 🎉 안내의 **연습 기록 파일로 받기**로 내려받을 수 있다. 직접 만든 탭은 남긴다.

## 데이터 저장 방식

DB를 쓰지 않고 **이 브라우저(localStorage)** 에 저장한다. 같은 기기의 같은 브라우저에서는 창을 닫아도 계속 남는다.

- 폰과 PC 사이에는 동기화되지 않는다. 주로 쓸 기기를 하나 정해서 쓴다.
- 브라우저의 사이트 데이터를 지우면 기록도 함께 사라진다. 시크릿 모드에서는 저장되지 않는다.
- 매달 처음 열 때 백업 알림이 뜬다. **지금 백업 저장**을 한 번 눌러 둔다. 언제든 **백업 파일 저장** 버튼으로도 저장할 수 있다. 기기를 바꿀 때는 새 기기에서 **백업 불러오기**를 하면 된다.
