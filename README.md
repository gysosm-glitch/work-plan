# Work Plan

학기 시간표, 시험, 자격증, 고정 일정을 한 화면에서 관리하는 일정 대시보드.

## 이렇게 쓰기

- **매일 아침 (1분):** 상단 브리핑에서 오늘 일정과 다음 시험 D-day를 본다. "지금 준비할 과목"이 1개 이상이면 시험 표를 연다.
- **공부한 날 저녁 (30초):** 시험 표에서 그 과목의 진도 슬라이더를 올린다. 100%가 되면 "준비 완료"로 바뀐다.
- **일요일 밤 (5분):** 캘린더에서 다음 주에 색이 진한 날(바쁜 날)과 흰 날(한가한 날)을 확인한다. "공부하기 좋은 날" 목록의 날짜를 눌러 공부 일정을 미리 넣어 둔다.
- **자격증·약속이 생기면:** 캘린더에서 그 날짜를 누르고 오른쪽 칸에서 추가한다.
- **시간표·시험 날짜가 바뀌면:** `data.js`를 고쳐서 push한다. Vercel이 자동으로 다시 배포한다. 휴강일은 `skip`에 날짜를 넣는다.

## 데이터 저장 방식

DB를 쓰지 않고 **이 브라우저(localStorage)** 에 저장한다. 같은 기기의 같은 브라우저에서는 창을 닫아도 계속 남는다.

- 폰과 PC 사이에는 동기화되지 않는다. 주로 쓸 기기를 하나 정해서 쓴다.
- 브라우저의 사이트 데이터를 지우면 기록도 함께 사라진다. 시크릿 모드에서는 저장되지 않는다.
- 일주일에 한 번 **백업 파일 저장**을 눌러 둔다. 기기를 바꿀 때는 새 기기에서 **백업 불러오기**를 하면 된다.
