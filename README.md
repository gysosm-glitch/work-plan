# Work Plan

학기 시간표, 시험, 자격증, 고정 일정을 한 화면에서 관리하는 일정 대시보드.

## 화면

- **🗓️ 주간 계획 (처음 화면):** 고정 시간표를 한 주 단위로 보여준다. 날짜를 누르면 🎯 활동 탭의 그날 일정으로 간다.
- **📆 월간:** 바쁜 날은 진하게, 시험 날짜는 🎯로 표시한다.
- **📚 교과:** 과목별 주차 칸(중간고사가 없으면 1주차부터, 봤으면 9주차부터 시험 전 주까지). 칸을 누르면 이번 회독 진도 %, 회독 수, 어디까지 했는지 메모를 기록한다. ✅ 1회독 완료를 누르면 회독 +1, 진도는 0%로 돌아간다. 필요 없으면 탭의 ✕로 숨긴다.
- **🎯 활동:** 위에는 그날 일정(‹ › 날짜 이동). 아래에는 활동 카드. 🤖 AX 프로젝트·스터디와 🎸 동아리는 처음부터 있고, 고정 시간표의 회의·동아리 일정 중 카드 이름(AX, 동아리)이 들어간 것(예: 화 AX 프로젝트 회의·동아리 활동, 목 AX 스터디)은 이번 주 칸으로 자동으로 생기고, 일정 시간이 지나면 ✅ 준비 끝(100%)이 된다(직접 적은 %가 있으면 그 값이 우선). 🗓️ 주간 계획의 해당 블록에도 준비 상태 배지가 붙는다. 그 밖의 준비할 일은 카드 안 **＋ 칸 추가**로 만든다. 칸을 누르면 준비 %와 어디까지 했는지를 적고, 100%면 ✅. 필요 없는 칸은 🗑️ 칸 삭제. "칸 직접 만들기"를 끄고 만든 항목(자격증·책 등)은 단원마다 회독·진도·메모를 기록한다.
- **✅ 이번 주 준비할 것:** 매주 월요일 2주 안의 시험과 지난주에 직접 적은 항목(못 한 것은 ⏩ 이월)으로 자동으로 채워진다. 필요 없는 건 지운다.
- **＋ 탭 추가:** 나만의 탭(체크리스트 + 메모)을 만들고 ✕로 지운다.

## 이렇게 쓰기

- **일요일 밤:** 🗓️ 주간 계획으로 다음 주를 보고, ✅ 준비할 것에 할 일을 적는다.
- **공부한 뒤:** 📚 교과 / 🎯 활동 탭에서 그 주차·단원 칸을 눌러 진도 %와 어디까지 했는지 적는다. 한 바퀴 끝나면 ✅ 1회독 완료.
- **시간표·시험이 바뀌면:** ⚙️ 시간표·시험 편집에서 고친다.

## 연습 기간과 2027년 시작

- 2026/12/31까지는 연습 기간이다. 화면 위에 🧪 안내가 뜬다.
- 2027년에 처음 앱을 열면 한 번만 2026년 일정·준비할 것·과목 진도·편집한 시간표를 정리한다(단원식 진도 항목과 탭은 남기고, AX·동아리 같은 활동 카드의 칸은 비운다). 지우기 전에 사본(`wp.practice`)을 보관하고, 🎉 안내의 **연습 기록 파일로 받기**로 내려받을 수 있다. 직접 만든 탭은 남긴다.

## 데이터 저장 방식

DB를 쓰지 않고 **이 브라우저(localStorage)** 에 저장한다. 같은 기기의 같은 브라우저에서는 창을 닫아도 계속 남는다.

- 폰과 PC 사이에는 동기화되지 않는다. 주로 쓸 기기를 하나 정해서 쓴다.
- 브라우저의 사이트 데이터를 지우면 기록도 함께 사라진다. 시크릿 모드에서는 저장되지 않는다.
- 매달 처음 열 때 백업 알림이 뜬다. **지금 백업 저장**을 한 번 눌러 둔다. 언제든 **백업 파일 저장** 버튼으로도 저장할 수 있다. 기기를 바꿀 때는 새 기기에서 **백업 불러오기**를 하면 된다.
