# Work Plan

학기 시간표, 시험, 자격증, 고정 일정을 한 화면에서 관리하는 일정 대시보드.

## 화면

- **📋 일간 계획:** 그날의 고정 시간표와 직접 넣은 일정을 보여준다. 📍 특이사항 · 공부 계획 칸에서 약속·✏️ 공부·🗂️ 스터디 준비 등을 날짜와 시간으로 넣는다.
- **🗓️ 주간 계획:** 고정 시간표 + 직접 넣은 일정. 공부는 자동으로 배분하지 않고 직접 계획한다.
- **📆 월간:** 바쁜 날은 진하게, 시험 날짜는 🎯로 표시한다.
- **📊 진도·복습:** 과목은 중간고사가 없으면 1주차부터, 봤으면 9주차부터 시험 전 주까지. 자격증·책·인강은 ＋ 진도 항목 추가(이름·단위·개수)로 만든다. 칸마다 복습 %(0~100)를 고르고, 항목별 평균을 막대로 보여준다. 필요 없으면 ✕로 지운다.
- **✅ 이번 주 준비할 것:** 매주 월요일 2주 안의 시험과 그 주에 넣은 일정, 지난주에 직접 적은 항목(못 한 것은 ⏩ 이월)으로 자동으로 채워진다. 필요 없는 건 지운다.
- **＋ 탭 추가:** 나만의 탭(체크리스트 + 메모)을 만들고 ✕로 지운다.

## 이렇게 쓰기

- **일요일 밤:** 다음 주 공부·스터디 준비를 일간 계획에서 날짜별로 넣는다. 주간 계획 탭에서 한눈에 확인한다.
- **공부한 뒤:** 📊 진도·복습 탭에서 그 주차·단원의 복습 %를 고른다.
- **시간표·시험이 바뀌면:** ⚙️ 시간표·시험 편집에서 고친다.

## 연습 기간과 2027년 시작

- 2026/12/31까지는 연습 기간이다. 화면 위에 🧪 안내가 뜬다.
- 2027년에 처음 앱을 열면 한 번만 2026년 일정·준비할 것·과목 진도·편집한 시간표를 정리한다(직접 만든 진도 항목과 탭은 남긴다). 지우기 전에 사본(`wp.practice`)을 보관하고, 🎉 안내의 **연습 기록 파일로 받기**로 내려받을 수 있다. 직접 만든 탭은 남긴다.

## 데이터 저장 방식

DB를 쓰지 않고 **이 브라우저(localStorage)** 에 저장한다. 같은 기기의 같은 브라우저에서는 창을 닫아도 계속 남는다.

- 폰과 PC 사이에는 동기화되지 않는다. 주로 쓸 기기를 하나 정해서 쓴다.
- 브라우저의 사이트 데이터를 지우면 기록도 함께 사라진다. 시크릿 모드에서는 저장되지 않는다.
- 매달 처음 열 때 백업 알림이 뜬다. **지금 백업 저장**을 한 번 눌러 둔다. 언제든 **백업 파일 저장** 버튼으로도 저장할 수 있다. 기기를 바꿀 때는 새 기기에서 **백업 불러오기**를 하면 된다.
